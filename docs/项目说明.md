## 一、项目概述

医疗运营数据主题分析平台是面向医院运营管理部门的一站式数据分析平台。平台通过整合 HIS（门诊/住院）、EMR（电子病历）、LIS（检验）、财务收费等多源业务数据，构建面向运营主题的数据仓库，提供指标计算、多维分析、可视化看板与大模型智能问数服务，辅助管理者实现数据驱动的精细化运营决策。

平台按“数据接入层 → 核心计算层 → 分析应用层”三层组织，数据侧遵循 ODS → DWD → DWS → ADS 分层建模，应用侧以统一 RESTful API 支撑管理驾驶舱、科室运营看板与专题分析看板，并以自然语言问数降低业务人员的使用门槛。

**建设定位**：不替代 HIS/EMR/LIS 等生产系统，而是作为其上的运营数据整合与分析层，形成“数据—分析—决策—验证”闭环。

## 四、业务处理流程（端到端数据流转链路）

1. **数据源**：医院 HIS、EMR、LIS 等业务系统产生门诊挂号、就诊、处方、住院、检验、收费等原始业务数据；同时存在医保结算、绩效考核等 Excel/CSV 报表文件。
2. **数据采集**：ETL 调度平台按预设周期（T+1 日终批为主，关键指标可按小时增量）通过 JDBC、文件解析、API 拉取等方式将源数据抽取到贴源层（ODS），并记录采集日志。
3. **数据清洗与加工**：对 ODS 数据去重、空值处理、编码标准化（科室/病种/收费项目字典映射）、脱敏处理（患者隐私字段），写入明细层（DWD），形成标准化明细宽表。
4. **指标汇总计算**：按业务主题与时间粒度在汇总层（DWS）聚合，再由指标计算任务在应用层（ADS）产出门诊量、床位使用率、平均住院日、次均费用、药占比等指标结果表。
5. **质量校验**：每批次加工完成后自动执行数据质量规则（行数波动、主键唯一、值域检查、与源系统对账），生成质量报告，异常时阻断下游发布并告警。
6. **服务提供**：后端服务读取 ADS 层结果数据，通过统一 RESTful API 提供指标查询、多维分析、看板数据接口，并进行鉴权与审计。
7. **分析应用**：前端看板与报表通过 API 渲染可视化图表；用户可进行维度下钻、对比分析、数据导出。
8. **智能分析**：用户以自然语言提问（如“上月呼吸科床位使用率趋势如何”），大模型将问题解析为指标查询意图并生成 SQL/接口调用，返回数据与图表，并自动生成文字结论与运营报告。
9. **反馈闭环**：管理决策结果反馈至业务系统，新的运营数据持续回流平台，形成“数据—分析—决策—验证”闭环。

**链路示意图**

```
HIS/EMR/LIS/财务/文件
        │ JDBC / 文件解析 / API
        ▼
   ODS 贴源层 ──→ 质量校验（批次级）──→ DWD 明细层（清洗+脱敏+标准编码）
        │                                      │
        └────────── 采集日志/批次号 ────────────┤
                                               ▼
                                    DWS 主题汇总层（日/月粒度）
                                               ▼
                                    ADS 指标结果层（30+ 指标）
                                               ▼
                     FastAPI 统一接口（鉴权 + 审计 + 缓存）
                                               ▼
        Vue3 + ECharts 看板/报表   ←──   大模型智能问数 & 报告生成
```

## 九、术语表

| 术语 | 含义 |
| --- | --- |
| ODS / DWD / DWS / ADS | 贴源层 / 明细层 / 汇总层 / 应用层 |
| 门诊人次 | 统计期内门诊就诊记录数（按 `visit_id` 去重） |
| 出院人次 | 统计期内办理出院手续的住院次数 |
| 实际占用总床日数 | 各出院患者住院天数之和，用于床位使用率计算 |
| 床位使用率 | 实际占用总床日数 ÷（开放床位数 × 统计天数） |
| 平均住院日 | 实际占用总床日数 ÷ 出院人次 |
| 次均费用 | 统计期费用合计 ÷ 对应人次 |
| 药占比 / 耗占比 | 药品收入 / 耗材收入 占医疗收入的比例 |
| DRG / DIP | 疾病诊断相关分组 / 病种分值付费 |
| CMI | 病例组合指数，出院病例 DRG 权重均值，反映收治难度 |
| 费用/时间消耗指数 | 实际费用（住院日）与同组标准值之比，>1 表示超支 |
| NL2SQL | 自然语言转 SQL，支撑智能问数 |
| RBAC | 基于角色的访问控制 |
| T+1 | 数据在业务发生次日完成加工入库 |
