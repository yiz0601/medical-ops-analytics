## 一、评审机制

| 项 | 约定 |
| --- | --- |
| 触发条件 | 每个阶段合并前、每次对外提交（commit）后、口径变更与安全相关改动 |
| 评审方式 | 自查清单 + 交叉评审（`CONTRIBUTING.md` 第 4 章 8 项清单）+ CI 门禁（`etl-smoke` / `api-tests` / `web-build` / `llm-eval`） |
| 评审清单 | 口径一致性、数据安全、幂等性、数据质量、命名规范、测试、文档同步、无死代码 |
| 记录方式 | 本文件按阶段登记：问题 → 发现方式 → 处理 → 验证证据 |
| 门禁指标 | pytest 覆盖率 ≥ 80%（实测 88.00%）、ETL 冒烟 57 项断言、文档完整性 47 项断言、前端构建成功 |

### 2.3 阶段三（数仓与指标）
