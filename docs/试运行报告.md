### 2.3 两种环境差异说明

| 差异项 | 本机试运行环境 | 目标（生产）环境 | 对试运行结论的影响 |
| --- | --- | --- | --- |
| 数据库 | SQLite（单文件，无并发写竞争） | MySQL 8.0（连接池 pool_size=10 / max_overflow=20） | 并发与锁行为不同，**50 并发压测结论须在目标环境复测**（LV-02） |
| 建表方式 | 应用启动时 `ensure_schema()` + ETL 建表脚本自动落地 | `sql/00_init_all.sql` 一次性执行（含索引优化） | 本机已验证脚本可执行；MySQL 语法版执行结果待目标环境确认 |
| Web 服务 | Uvicorn 单进程开发模式 | Nginx 反代 + 容器内多 worker | 首屏与静态资源指标（首屏 ≤ 2 s）未在目标环境验证 |
| 大模型 | 未配置 API Key，走离线规则引擎（评测 50/50 = 100%） | 对接 OpenAI 兼容接口（`MOA_LLM_BASE_URL` / `MOA_LLM_API_KEY`） | 在线问数准确率与响应时延待目标环境验证（LV-03） |
| 传输安全 | HTTP（127.0.0.1） | 强制 HTTPS + HSTS（建议） | 传输加密与暴露面核查未执行（LV-05） |
| 容器健康 | `health_check.py` 降级为 HTTP 探针模式 | `docker inspect` 校验 Health.Status | 容器健康检查链路待目标环境验证（LV-01） |
| 数据源通道 | 7 个数据源对象均为 CSV 文件通道（`source_type: csv`） | HIS/EMR/LIS 直连（MySQL/Oracle/SQL Server）+ Excel + 第三方 API | 直连通道未联调，仅验证文件通道（LV-06） |
